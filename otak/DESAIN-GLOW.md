# DESAIN-GLOW: Sistem Desain v3 (rombak TOTAL per penolakan pemilik 2026-11-28)

Penolakan pemilik: desain PAGI CERIA dinilai 1/10 - "rombak total". Diagnosa
kegagalan: latar krem datar + bubble putih polos terlihat seperti screenshot
dokumen chat, bukan desain. Datar, tanpa kedalaman, tanpa momen yang bikin
berhenti scroll. Maka bahasa visual lama DIBUANG SEMUA (warna, permukaan,
layout, transisi) dan dibangun ulang sebagai **GLOW v3**.

## Enam prinsip GLOW

1. HIDUP - latar bukan warna datar: gradien pastel 4-stop yang bergeser
   pelan + 5 blob bokeh besar (coral, rose, lilac, aqua, butter) berdrift
   + kilau sparkle. Frame pertama langsung terasa "beda dari yang lain".
2. KACA (glassmorphism) - semua permukaan kaca buram semi-transparan,
   ring gradien, glow warna karakter: ada kedalaman, bukan kertas rata.
3. SINEMATIK - 4 hero scene ilustrasi AI full-screen (buka judul, poster
   materi 1, poster materi 2, CTA penutup) dengan gerak Ken Burns + scrim
   + judul display. Momen poster di antara alur chat menjaga tempo.
4. TIPOGRAFI DISPLAY - judul besar tebal, aksen teks gradien
   (background-clip), chip gradien, bar progres cerita 5 segmen ala story.
5. SATU PALET hangat-cerah konsisten - teks plum #43304F (bukan hitam
   pekat), aksen coral #FF6B8A, tangerine #FF9E5E, kuning #FFC94D, mint
   #4DD6A8, langit #5BA8F5, anggur #9B7BF5, emas #E8A80C.
6. Produksi 9:16 SAJA (L1 revisi tetap; landscape diarsipkan).

## Komponen

- Latar: gradien #FFEDD9 -> #FFD9E8 -> #E8DCFF -> #D6F1FF + blob blur
  besar drift pelan + sparkle putih/kuning melayang
- Header kaca + tiga dots gradien; bar progres cerita di bawah header
- Bubble glass per chara (ring gradien warna chara + glow lembut); KAMU
  kaca gradien peach-pink; akun resmi kaca emas
- Avatar ikon SVG digambar custom dalam ring gradien per chara
- Foto chat: kartu kaca + ilustrasi SVG dunia (papan resep, papan takaran,
  resep dobel, voting)
- Sisipan meme: kaca penuh, ilustrasi AI bingkai putih glow, label gradien
- Diagram menyala: kartu kaca + band gradien + fill coral/mint + angka
- Kuis: kartu kaca besar + kartu bantu gradien + CTA gradien
- Subtitle: pil kaca teks plum; watermark pil kaca + titik gradien
- Hero scene: full-bleed + Ken Burns + scrim gradien plum + judul display
- Endcard: kaca + bar gradien + fade ke gradien terang (bukan hitam)

## Kenapa ini bikin penonton betah

- Gerak halus terus-menerus (blob + sparkle + Ken Burns) = mata tidak
  pernah lihat frame diam
- Kaca + gradien + glow = bahasa desain aplikasi modern yang terasa mahal
- Warna karakter konsisten dari bubble sampai suara = penonton langsung
  tahu siapa bicara tanpa membaca nama
- Ritme chat -> poster -> chat = ada napas, tidak monoton
